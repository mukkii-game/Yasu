# 犯人はヤス

誰もが知っている答えを2文字で入力する、短編8ビット推理アドベンチャーです。

## 遊び方

- ゲーム画面のどこかをタップ／クリック、または任意のキーで会話を進めます。
- 50音パネルから犯人の名前を2文字で選び、「けってい」を押します。
- `THE END` では、画面のどこかを押すとタイトルへ戻ります。

## 開発

```sh
npm ci
npm run dev
```

品質確認には `npm run typecheck`、`npm test`、`npm run build`、`npm run test:e2e` を使います。`main` に反映されたビルドは、リポジトリ既存のワークフローからGitHub Pagesへ公開されます。

## 画面仕様

表示はファミコンと同じ論理解像度の256×240ピクセルです。16色の固定パレットを使い、1倍・2倍・3倍の整数拡大だけで表示します。セリフは `ヤス「……」` の形で一文字ずつ表示されます。

通常画面には、輪郭なしの白い「ヤ」「ス」と縦書きされた丸いのっぺら顔と四角い上半身のヤスだけが立ちます。正解時も背景や色は変わらず、ヤスが小刻みに震えて高い「バ・バーン」が鳴るだけです。ツッコミは前半と大きな「ヤスッ！」が共通の二段テンポで画面中央に現れ、両方に8ビット効果音が付きます。セリフの文字送り、カナ選択、決定にも短い効果音があり、BGMはありません。

夕焼けの `THE END` では、地平線へ半分沈んだ太陽を背に連行される二人が画面外へ歩きます。その後、大きな「このゲーム⋯」と、さらに大きな「ヤスッ！！」がほかのツッコミと同じ間で別々に切り替わります。後半を1秒見せてから画面全体がゆっくり消え、タイトルへ戻ります。
