# 犯人はヤス

誰もが知っている答えを2文字で入力する、短編8ビット推理アドベンチャーです。

## 遊び方

- ゲーム画面のどこかをタップ／クリック、または任意のキーで会話を進めます。
- 50音パネルから犯人の名前を2文字で選び、「けってい」を押します。
- `THE END` では、画面のどこかを押すとタイトルへ戻ります。

## 開発

```sh
npm ci
npm run dev
```

品質確認には `npm run typecheck`、`npm test`、`npm run build`、`npm run test:e2e` を使います。`main` に反映されたビルドは、リポジトリ既存のワークフローからGitHub Pagesへ公開されます。

## 画面仕様

内部画面はファミコンと同じ論理解像度の256×240ピクセルです。16色の固定パレットを使い、縦方向は1倍・2倍・3倍の整数拡大、横方向だけブラウン管表示を意識して補正し、画面全体を4:3で表示します。セリフは `ヤス「……」` の形で一文字ずつ表示されます。

タイトルと通常画面のヤスには、作者が描いた32×48ピクセルのPNG原画をそのまま使います。タイトルは原寸、通常画面は補間なしの正確な2倍（64×96ピクセル）で、ブラウザによるぼかしは行いません。タイトルでは原画だけを表示し、通常画面では肌色部分へ白い「ヤ」「ス」を縦に重ねます。顔と体は同じ原画から上下に切り分けているため、「はっはっは」では体だけが2ドット上下し、「まあ しょはんだし」では顔だけが二回うなずきます。通常画面は、横に広い額縁状の場面絵と、その直下の文章欄という簡潔な初期ファミコンADV風の構成です。使わないコマンド欄は置きません。正解直後はセリフを出さず、背景を変えないまま低い雷の「ガガーン」と大きな震えを1秒間入れてから話し始めます。白い全画面フラッシュはありません。ツッコミは前半と大きな「ヤスッ！」が共通の二段テンポで、顔や通常文章には重なりません。両方に8ビット効果音が付きます。セリフの文字送りは一段目テロップと同じ基準音量で、カナ選択、決定にも短い効果音があり、BGMはありません。

夕焼けの `THE END` では、連行される二人が以前の開始位置と左端の中間（X=41px）から一ドット上下しながら、2.4秒で左端へ消えます。人物はそこで完全に消えるため、テロップ後に再登場しません。その後、ゲーム中テロップを拡大した「このゲーム」「なにもかも」を二段で残したまま、いつもの間で下段に60ピクセルの「ヤスッ！」が加わります。後半を1秒見せてから画面全体がゆっくり消え、タイトルへ戻ります。エンディング中のクリックやキー入力は受け付けません。「まあ しょはんだし」のセリフを言い終えたときは、体を止めたまま顔だけが二回うなずきます。
