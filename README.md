# 犯人はヤス

誰もが知っている答えを2文字で入力する、短編8ビット推理アドベンチャーです。

## 遊び方

- 画面のタップ／クリック、または Enter / Space で会話を進めます。
- 50音パネルから犯人の名前を2文字で選び、「けってい」を押します。
- 右上の `♪` で効果音を切り替えられます。
- `THE END` では、画面のどこかを押すとタイトルへ戻ります。

## 開発

```sh
npm ci
npm run dev
```

品質確認には `npm run typecheck`、`npm test`、`npm run build`、`npm run test:e2e` を使います。`main` に反映されたビルドは、リポジトリ既存のワークフローからGitHub Pagesへ公開されます。

## 画面仕様

表示はファミコンと同じ論理解像度の256×240ピクセルです。16色の固定パレットを使い、1倍・2倍・3倍の整数拡大だけで表示します。セリフは `ヤス「……」` の形で一文字ずつ表示されます。

正解の瞬間だけ室内の色・ヤスの表情・画面の揺れが急変し、ファミコン音源を意識したパルス波・三角波・ノイズの短い恐怖音が鳴ります。BGMはありません。
